# ArtFlow

Booking and order management platform for commission-based artists (pencil artists, blood artists).

Supports — not replaces — the existing Facebook → WhatsApp → phone call workflow, by centralizing
bookings, image review, payments, and status tracking into one dashboard.

## Project Structure
- `client/` — React + Vite + Tailwind frontend
- `server/` — Node.js + Express backend
- `docs/` — project docs, booking flow diagrams, API notes
